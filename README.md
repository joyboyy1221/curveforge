# CurveForge ⚒️

**Visual launchpad for Meteora's Dynamic Bonding Curve (DBC) on Solana.**

> Design bonding curves visually. Simulate launches buy-by-buy. Deploy on-chain. Zero code required.

🔗 **[Live Demo](https://curveforge-weld.vercel.app)** · [Docs](https://docs.meteora.ag/developer-guides/dbc)

---

## The Problem

Configuring a Meteora DBC launch today means:

1. Writing 200+ lines of SDK code to set `sqrtPrices`, `liquidityWeights`, and fee schedules
2. Guessing parameter values, deploying to devnet, checking if the curve looks right
3. Repeating until the price discovery matches your launch strategy
4. No way to visualize the curve or simulate trades before deploying

This trial-and-error loop slows down every team building on DBC.

## The Solution

CurveForge provides six tools in one interface:

### 1. Curve Designer
Interactive parameter editor with real-time curve visualization. Pick a shape, set prices, drag segments — the bonding curve updates instantly on a logarithmic price chart.

**4 curve shapes:**
- **Linear** — even price movement
- **Exponential** — slow start, steep finish
- **Flat** — stable price with late graduation spike
- **S-Curve** — slow-fast-slow (sigmoid)

**Configurable parameters:**
- Start/End price, 1-16 segments
- Migration threshold (SOL)
- Fee mode (Exponential/Linear decay), Start/End fee, Decay duration
- DAMM v2 fee tier, Locked liquidity %

### 2. Preset Marketplace
Eight curated configurations for common launch types:

| Preset | Use Case | Multiplier | Shape |
|--------|----------|------------|-------|
| Meme Standard | Meme token launches | 10,000x | Exponential |
| Moon Mission | Maximum price range | 10,000x | Exponential |
| Equity / Stock | Tokenized RWA assets | 100x | Flat |
| RWA Bond | Fixed-income tokens | 5x | Flat |
| AI Agent | AI utility tokens | 10,000x | S-Curve |
| Community Fair | Equal opportunity | 500x | Linear |
| Wide Distribution | Broad distribution | 10x | Linear |
| DePIN Utility | Infrastructure tokens | 1,000x | S-Curve |

Click any preset → loads into the designer → customize further.

### 3. Launch Simulator
Step through the curve buy-by-buy:
- Input SOL amount → execute simulated buy
- Watch current price climb along the curve
- See tokens received per trade
- Track progress toward migration threshold
- Full trade history log

### 4. Config Export
Generate production-ready code for the Meteora DBC TypeScript SDK:

```typescript
import { buildCurveWithCustomSqrtPrices, createSqrtPrices } from "@meteora-ag/dynamic-bonding-curve-sdk";

const sqrtPrices = createSqrtPrices(
  [1e-9, 3.34e-7, 6.67e-7, 1e-6],
  TokenDecimal.NINE, 9
);

const curveConfig = buildCurveWithCustomSqrtPrices({
  // ... full config generated by CurveForge
});
```

Also exports raw JSON for custom tooling.

### 5. Wallet Connect + On-Chain Deploy
- **Phantom wallet** integration
- **Mainnet & Devnet** network toggle
- The deploy button builds a real `createConfig2` transaction with the official `@meteora-ag/dynamic-bonding-curve-sdk` and sends it to the DBC program. The result is a usable pool config owned by your wallet (fee claimer + leftover receiver), and its address is shown so you can launch pools from it.
- 4-step progress (Connect → Build Tx → Sign → Confirm), with links to the config account and the transaction on Solscan
- The transaction is simulated before it is sent, so an invalid config fails without costing anything
- Link to the official Devnet faucet for test SOL

Deployed configs use: SPL token, immutable token authority, fees collected in the quote token, dynamic fee on, no migration fee, no pool creation fee, and migration to DAMM v2. Change these in `src/dbc.js`.

### 6. Live Feed + Sharing
- **Live DBC program feed** — real-time transactions from the Meteora DBC program on Solana
- **Shareable config URLs** — encode your curve in a URL, share with anyone, they get your exact config loaded

## How It Uses Meteora DBC

CurveForge is built directly on the DBC specification:

- **Curve math** mirrors the on-chain constant-product segments — up to 16 points with logarithmic price scaling
- **Fee schedules** implement both `FeeSchedulerExponential` and `FeeSchedulerLinear` decay modes
- **Migration threshold** — with explicit segment prices the DBC program derives the quote amount that triggers DAMM v2 graduation from your prices, supply and weights. CurveForge computes it with the SDK and shows it as "On-chain threshold". The simulator still uses the threshold you type in, as an approximation
- **Liquidity weights** map directly to the `liquidityWeights` array in `buildCurveWithCustomSqrtPrices`
- **Export code** generates valid calls to `createSqrtPrices` and `buildCurveWithCustomSqrtPrices`
- **On-chain deploy** calls `client.partner.createConfig2` from the Meteora SDK against the DBC program (`dbcij3LWUppWqq96dh6gJWwBifmcGfLSB5D4DuSMaqN`). The exported code and the deploy button share the same parameters

## Run Locally

```bash
git clone https://github.com/joyboyy1221/curveforge.git
cd curveforge
npm install
npm run dev
```

Opens at `http://localhost:3000`.

Mainnet uses a public RPC by default. To use your own, create `.env` with:

```bash
VITE_MAINNET_RPC=https://your-rpc-url
```

## Build

```bash
npm run build
```

Output in `dist/`. Deploy anywhere that serves static files.
